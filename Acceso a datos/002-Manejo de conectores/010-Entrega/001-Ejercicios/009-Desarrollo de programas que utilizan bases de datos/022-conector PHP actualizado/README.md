# Ejemplos de conectores AndreiBBDD

La carpeta contiene ejemplos equivalentes para los conectores nativos de Python y PHP.

En Windows 11, ejecuta `compilar.bat` desde esta carpeta para generar `AndreiBBDD.exe`. El terminal carga su `config.json` junto al ejecutable; los ejemplos Python y PHP configuran el archivo explícitamente.
