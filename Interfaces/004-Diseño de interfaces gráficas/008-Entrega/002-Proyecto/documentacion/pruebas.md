# DOCUMENTACIÓN DE PRUEBAS

## Proyecto

Interfaces Naturales de Usuario

---

# Objetivo

Verificar el correcto funcionamiento de los componentes
desarrollados para la aplicación.

Las pruebas realizadas permiten validar tanto la creación
de componentes como el comportamiento de las acciones
implementadas mediante voz, gestos y movimiento corporal.

# Conclusión

Las pruebas realizadas permiten verificar el correcto
funcionamiento de los componentes visuales desarrollados
y de las funcionalidades implementadas mediante
reconocimiento de voz, detección de manos y detección
de movimiento corporal.

Todos los casos de prueba ejecutados han obtenido
resultados satisfactorios y el comportamiento observado
coincide con el esperado durante el diseño del sistema.
