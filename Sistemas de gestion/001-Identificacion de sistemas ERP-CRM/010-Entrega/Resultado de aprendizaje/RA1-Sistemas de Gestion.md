**002-Funciones de un ERP.md**
```markdown
Un **ERP (Enterprise Resource Planning)** gestiona de forma integrada los principales **recursos y procesos internos de una empresa**, centralizando la información en un mismo sistema.

Normalmente puede gestionar:

* **Ventas y clientes**: presupuestos, pedidos, albaranes, facturas, devoluciones, tarifas.
* **Compras y proveedores**: pedidos de compra, recepción de mercancía, facturas de proveedor, pagos.
* **Almacén e inventario**: existencias, entradas/salidas, ubicaciones, lotes, números de serie, inventarios.
* **Contabilidad y finanzas**: asientos, cuentas, balances, impuestos, tesorería, cobros y pagos.
* **Producción**: órdenes de fabricación, materias primas, escandallos, planificación, costes de producción.
* **Recursos humanos**: empleados, contratos, horarios, ausencias, vacaciones, nóminas —dependiendo del ERP—.
* **Proyectos y servicios**: tareas, horas trabajadas, costes, presupuestos y rentabilidad.
* **Logística**: expediciones, transporte, preparación de pedidos y entregas.
* **Activos y mantenimiento**: maquinaria, vehículos, instalaciones, mantenimiento preventivo y correctivo.
* **Informes y análisis**: ventas, márgenes, costes, rentabilidad, stock, productividad y KPIs.
```

async function cargarIncludes() {
  const elementos = document.querySelectorAll("[data-include]");
  for (const elemento of elementos) {
    const archivo = elemento.dataset.include;
    const respuesta = await fetch(archivo);

async function cargarIncludes() {

  const elementos = document.querySelectorAll("[data-include]");

  for (const elemento of elementos) {

    const archivo = elemento.dataset.include;

    const respuesta = await fetch(archivo);

    if (!respuesta.ok) {
      console.error("No se puede cargar:", archivo);
      continue;
    }

    elemento.innerHTML = await respuesta.text();

    // Ejecutar los scripts que hayan venido dentro del include
    const scripts = elemento.querySelectorAll("script");

    scripts.forEach(function(scriptViejo){

      const scriptNuevo = document.createElement("script");

      // Copiamos atributos por si los hubiera
      for (const atributo of scriptViejo.attributes) {
        scriptNuevo.setAttribute(
          atributo.name,
          atributo.value
        );
      }

      scriptNuevo.textContent = scriptViejo.textContent;

      scriptViejo.replaceWith(scriptNuevo);

    });

  }

}

cargarIncludes();

async function cargarIncludes() {

  const elementos = document.querySelectorAll("[data-include]");

  for (const elemento of elementos) {

    const archivo = elemento.dataset.include;

    const respuesta = await fetch(archivo);

    if (!respuesta.ok) {
      console.error("No se puede cargar:", archivo);
      continue;
    }

    elemento.innerHTML = await respuesta.text();

    // Ejecutar los scripts que hayan venido dentro del include
    const scripts = elemento.querySelectorAll("script");

    scripts.forEach(function(scriptViejo){

      const scriptNuevo = document.createElement("script");

      // Copiamos atributos por si los hubiera
      for (const atributo of scriptViejo.attributes) {
        scriptNuevo.setAttribute(
          atributo.name,
          atributo.value
        );
      }

      scriptNuevo.textContent = scriptViejo.textContent;

      scriptViejo.replaceWith(scriptNuevo);

    });

  }

}

Se han identificado y descrito los principales sistemas ERP-CRM utilizados actualmente:
- Odoo: ERP-CRM modular, open source con versión enterprise.
- Dolibarr: ERP-CRM ligero, open source, orientado a pequeñas empresas.
- SuiteCRM: CRM open source centrado en ventas, marketing y atención al cliente.
Se han documentado sus características principales y diferencias.

B- Identificación de los tipos de licencia de los sistemas ERP-CRM

Se han analizado las licencias más comunes:
- GPL (Dolibarr)
- LGPL (Odoo Community)
- AGPL (SuiteCRM)
- Licencias propietarias (Odoo Enterprise)
Se ha explicado cómo afectan a la distribución y modificación del software.

C- Comparación de sistemas ERP-CRM según características y requisitos

- Complejidad de instalación
- Requisitos de hardware y software
- Base de datos utilizada
- Módulos disponibles
- Curva de aprendizaje
